A comprehensive, web-based quality control and predictive analytics platform for manufacturing and process industries. Built with Streamlit and powered by advanced machine learning capabilities.

## 🚀 Features

### 📐 Quality Metrics
- **Process Capability Indices**: Cp, Cpk, Pp, Ppk, Cmk calculations
- **Six Sigma Analytics**: DPMO and Sigma Level analysis
- **Real-time Calculations**: Instant metric computation with interpretation
- **Visual Analysis**: Distribution plots with specification limits

### 📈 Statistical Process Control (SPC)
- **Control Charts**: X-bar and R charts with automatic limit calculation
- **Out-of-Control Detection**: Identify process variations
- **Subgroup Analysis**: Configurable subgroup sizes
- **Trend Analysis**: Monitor process stability over time

### 🔍 Defect Analysis
- **Pareto Analysis**: Identify vital few defect contributors
- **Categorical Analysis**: Stratify defects by multiple categories
- **Defect Rate Calculations**: Overall and category-specific rates
- **Visual Insights**: Interactive Pareto charts

### 🎯 AI-Powered Sampling Recommender
- **Data-Type Specific**: Recommendations for variable vs attribute data
- **Application-Focused**: Process control, lot acceptance, capability analysis
- **Industry Best Practices**: Based on ANSI/ASQ standards
- **Visual Guidance**: Suitability scoring for different methods

### 🔬 Advanced Analytics
- **Normality Testing**: Shapiro-Wilk tests with Q-Q plots
- **Correlation Analysis**: Heatmaps and matrix visualization
- **Distribution Comparison**: Multiple variable analysis
- **Statistical Diagnostics**: Comprehensive data quality checks

### 📊 Machine Learning & Forecasting
- **Automated ML**: PyCaret integration for model comparison
- **Quality Prediction**: Regression models for quality scores
- **Feature Importance**: Identify key process parameters
- **Time Series Forecasting**: Trend analysis and predictions

### 📁 Enhanced Data Management
- **Multiple Import Sources**: CSV upload, Excel files, Google Sheets integration
- **Robust Error Handling**: Comprehensive file validation and error recovery
- **Data Quality Checks**: Automatic missing value analysis and data validation
- **Real-time Preview**: Instant data exploration with quality assessment
